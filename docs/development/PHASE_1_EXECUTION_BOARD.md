## 5. Findings and documentation conflicts

1. **Stale security gate text.** `docs/security/ABAC_GATE.md` said "Status: not implemented", which contradicts the delivered FORCE-RLS, signed-actor-context and audit work. Corrected in P1-PR01 to cite the current evidence and keep the real-data gate and remaining work explicit.
2. **Toolchain mismatch.** Local Node 22 versus the required Node 26.13.1; local turbo-driven scripts fail. Rely on CI for `pnpm build`/`pnpm typecheck` and record local limits in every PR.
3. **Vault schema changes are unprotected.** The farmer vault has no handling for a schema upgrade while another tab holds the database open. Needed for P1-F03 independent of enrollment.
4. **Staging does not exist.** WP05 cannot be demonstrated from the current repository; it needs the owner's host decision and is the largest hours risk.
5. **Not verified:** field PWA production build and compiled Chromium suite were not run in this audit.
